# Descriptive Statistics and Visualisation

This Excel coursework collection shows the foundations of exploratory analysis, progressing from distributions to a larger real-estate case study.

## Skills demonstrated

- Frequency tables and histograms
- Bar, pie, Pareto, and scatter charts
- Cross-tabulations
- Mean, median, mode, skewness, variance, standard deviation, and coefficient of variation
- Covariance and correlation analysis
- A multi-sheet descriptive analysis of a real-estate dataset

The files are organised in the order the techniques build on one another. They contain completed coursework, not the supplied solution files.
