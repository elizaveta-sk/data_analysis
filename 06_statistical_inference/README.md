# Statistical Inference

Completed Excel exercises applying confidence intervals and hypothesis tests to practical datasets, including employee and shoe-size examples.

## Skills demonstrated

- Standard normal distribution calculations
- Confidence intervals for dependent and independent samples
- One-sample, paired-sample, and independent-sample tests
- Known- and unknown-variance scenarios
- Workforce hypothesis testing with multiple worksheets and formulas

Reference z- and t-table files and course answer keys are intentionally excluded.
