# Sales Forecasting

This notebook compares several ways to forecast and explain sales using a TechGear dataset.

## What it demonstrates

- Multiple linear regression using advertising spend and discount rate
- Decision-tree regression
- Five-fold cross-validation with RMSE comparison
- Three-month moving average and simple exponential smoothing
- MSE, MAE, and MAPE error measures

## Running the notebook

The notebook downloads its public course datasets directly, so no data file is stored in this repository. Install `pandas`, `matplotlib`, `scikit-learn`, `statsmodels`, and `openpyxl`, then run the notebook from top to bottom.
